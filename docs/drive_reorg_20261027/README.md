# Google Drive 整理（2026-10-27, LEGION の Claude Code）

- YouTube投稿 を作品ごとのフォルダ「作業名_日本語名」に整理。各フォルダの直下に投稿用の一式、`収録元/`・`資料/`・`旧版/` に残りを置く
- マイドライブ直下にあったファイル91件を、作品フォルダ・`00_ルート直下の整理/` の分類・`Instagram投稿/` へ移した。直下のファイルは0件
- 削除はしていない。`move_log.tsv` に元の親フォルダIDが残っているので、`gog drive move <id> --parent <元の親>` で戻せる
- 既存のトップのフォルダ（.secrets・Backups・Mimura-Brain-Compact など）は、スクリプトが場所を前提に使っているので動かしていない
- `upload_brief.py` は、作業名に完全一致するフォルダが無いときに「作業名_」で始まるフォルダを探すようにした
- 新しい録画（OBS）は今まで通り YouTube投稿 の直下に落ちる。仕上げが済んだら、その作品の `収録元/` へ移す
