# サムネイルの記録

良い型を見つけて、それを続けるための台帳（2026-10-15 開始）。
長尺を出すたびに1行足す。クリック率は Studio でしか見えない（API では取れない）ので三村さんに読んでもらう。

## いま分かっていること

- 直近の長尺は流入の7〜8割が「登録チャンネル」。初日の再生は**押されるか**で決まり、解説の中身は効かない
- 中身が効くのは2日目以降の伸びと、次の動画のクリック。こちらは視聴維持率で見る
- 再生数はネタの格・同じネタの連続にも左右される。サムネの良し悪しは**クリック率**で比べる
