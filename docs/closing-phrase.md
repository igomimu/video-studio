# 収録の締めの定型フレーズ（2026-10-22 三村さん決定）

YouTube・みむ囲碁ラジオの収録では、毎回最後にこれを言う。文面は三村さん本人のもの。言い換えない（◯◯だけ毎回入れ替える）。

> ということで今回は◯◯についてお伝えしました。
> 如何でしたか？
> この動画が気に入った方は高評価、チャンネル登録を、ぜひお願いします。
> また、ニュースレターもやっていますので、そちらも合わせてお願いします。
> それではまた次の動画でお会いしましょう、囲碁棋士の三村智保でした。

- 2026-10-22 に一度AI案を採用したが、同日に三村さん本人がこの文面に差し替えた（「お愛しましょう」→「お会いしましょう」の誤字だけ直した）
- 理由: 動画の中で口頭で呼びかけたときだけ登録が動いた（2025-05、1本の動画から2日で22人）。説明欄に置くだけでは8日間0件だった
- 説明欄のリンクは `upload_brief.py` が自動で足す（無ければ末尾に追加し、`?src=youtube` / `?src=spotify` の印も付く）。どの媒体から登録されたかは購読者の記録で数えられる
- 効果が数字で出たら `~/.secretary/winning-moves.md` に1行足す
