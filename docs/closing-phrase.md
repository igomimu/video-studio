# 収録の締めの定型フレーズ（2026-10-22 三村さん決定）

YouTube・みむ囲碁ラジオの収録では、毎回最後にこれを言う。言い換えない。

> 最後に一つだけお知らせです。
> 毎週、無料のメール『みむいご通信』を出しています。
> 今週の問題や棋戦のニュースを、私が書いてお届けしています。
> 概要欄のリンクから登録できますので、よかったら読んでみてください。
>
> それでは、今週もあなたが幸せでありますように。
> 三村智保でした。

- 理由: 動画の中で口頭で呼びかけたときだけ登録が動いた（2025-05、1本の動画から2日で22人）。説明欄に置くだけでは8日間0件だった
- 説明欄のリンクは `upload_brief.py` が自動で足す（無ければ末尾に追加し、`?src=youtube` / `?src=spotify` の印も付く）。どの媒体から登録されたかは購読者の記録で数えられる
- 効果が数字で出たら `~/.secretary/winning-moves.md` に1行足す
